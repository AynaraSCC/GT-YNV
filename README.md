# Golden Ticket — maqueta reconstruida

Landing page de una sola página, con desplazamiento vertical y estética negra/dorada.

## Verla
Abre `index.html` en el navegador o usa Live Server desde Visual Studio Code.

## Fotografías de la galería
Guarda tus imágenes en `assets/images/` con estos nombres exactos:
- `img1.jpg` — boda
- `img2.jpg` — quince años
- `img3.jpg` — grado universitario

Las rutas están definidas en `css/styles.css`, en `.photo-one`, `.photo-two` y `.photo-three`.

## Contenido
- Portada y explicación explícita de que Golden Ticket es una rifa.
- Descripción del premio, valor e inclusiones.
- Galería con tres espacios para imágenes.
- Tiquetes dorados animados después de la galería.
- Cuadrícula ilustrativa del 001 al 1000.
- Espacio reservado y deshabilitado para un futuro enlace de pago.
- Preferencias de celebración, invitados, exclusiones y nota informativa.

## Alcance de esta maqueta
La cuadrícula es visual. No hay selección, reserva, compra, base de datos, captura de cédula/contacto, procesamiento de pagos ni confirmación de participaciones. No introduzcas datos personales reales. La maqueta no debe presentarse como una rifa habilitada para participar.
